# website

Project website. Currently the default Vite + TypeScript starter page.

## Usage

Run `vp run website#dev` and open the printed URL. Edit `src/main.ts` to change the page; it reloads on save.

## Commands

```bash
vp run website#dev      # start the dev server
vp run website#build    # type-check and build
vp run website#preview  # preview the build
```
